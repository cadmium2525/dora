# モンスターコンストラクション攻略 — カード一覧

`cadmium2525/monster_collection` のマスターデータを参照して作った、独立した静的攻略サイトです。元ゲームのリポジトリには変更を加えていません。

## ローカルで確認する

`index.html` を直接開く代わりに、フォルダを静的サーバーで配信してください（ブラウザの `fetch` 制限を避けるため）。例えば Node.js がある環境では次のように起動できます。

```text
npx serve .
```

データは `data/master-data.json`、カードアートは `assets/images/` に分離しています。ゲーム側でマスターデータを更新した場合は、同じファイルと画像フォルダを差し替えるだけで一覧へ反映できます。
